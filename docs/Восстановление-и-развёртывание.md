## 3. Бутстрап «с нуля» (порядок шагов)

1. **VM + ОС:** Ubuntu 26.04.1, обновления, chrony, unattended-upgrades, qemu-guest-agent.
2. **Пользователи/группы:** `ocadmin` (1000:1000, sudo — `infra/sudoers/90-ocadmin`), `openclaw`
   (997:981, home `/srv/openclaw`, shell bash), группа `shared` (gid 2000): `openclaw,ocadmin,www-data`.
3. **SSH:** ключи root/ocadmin; `infra/ssh/01-hardening.conf` → `/etc/ssh/sshd_config.d/` — **имя файла
   должно идти первым по алфавиту** (§1.1: cloud-init кладёт `50-cloud-init.conf` с `PasswordAuthentication yes`,
   sshd берёт первое совпадение). Проверка: `sshd -T | grep -i password`.
4. **Сеть:** netplan из `infra/netplan/` (cloud-init + GRE-туннель `gre-lab` до MikroTik 195.133.249.150,
   MTU 1476, маршруты лабораторных сетей — см. файл).
5. **Базовое ПО:** Docker + containerd, Docker Compose v5.5.0, fail2ban (`infra/fail2ban`), zabbix-agent
   (`infra/zabbix`).
6. **Директории:** `/srv/{openclaw,nextcloud,caddy,projects,shared}`; `/srv/shared/*` — group `shared`,
   setgid, UMask 0002 (ADR-003). `/opt`: whisper.cpp + `whisper-models/ggml-medium-q5_0.bin`, piper +
   piper-voices, parakeet, miniforge, hf-cache, ttsbench.
7. **Nextcloud:** `docker build` по `infra/nextcloud/Dockerfile` → `nextcloud-shared:34`; `.env` из
   `env.example` + секреты; `docker compose up -d` по `infra/nextcloud/compose.yaml` (postgres:17-alpine
   с тюнингом, redis:7-alpine, nc-app, nc-push, nc-cron); `occ`: trusted_domains = `localhost`,
   `cloud.paylama.tech`; memcache: APCu (local) + Redis (distributed); приложения notify_push 1.4.0, office 1.0.0.
8. **Caddy edge:** docker-сеть `edge` со static IP `172.18.0.10` на контейнере `caddy`; `infra/caddy/`
   (TLS-email `maintechlead@yandex.ru` — заменить на свой).
9. **OpenClaw Gateway:** установить OpenClaw 2026.8.2 (CLI в `/usr/local/bin/openclaw`, Node 24.20.0);
   `/etc/openclaw/env` (по `infra/openclaw/env` + секреты); юнит `infra/systemd/openclaw-gateway.service`
   → `systemctl enable --now openclaw-gateway`; **не вызывать `openclaw` под root** (§1.2) — команда `oc`.
   Модельная цепочка — ADR-004 (`polza-ds/deepseek/deepseek-v4.1-flash` + фолбэки; ключи провайдеров —
   в профиле агента, не в git); STT — parakeet-cli, TTS — `ru-RU-SvetlanaNeural` (см. Архитектура-и-ресурсы.md §5).
   Дальше — настройка агентов/каналов через Control UI (`oc devices approve`), Telegram-бот
   @MainTechOpenClaw_Bot (chat_id 10292232).
10. **BAS-IP Monitor:** код `/srv/projects/bas-ip-monitor`, сборка `basip-monitor-app` по
    `infra/basip-monitor/Dockerfile`, `docker compose -f infra/basip-monitor/docker-compose.yml up -d`,
    миграции (`alembic upgrade`), Caddy на :8080.
11. **Ollama:** `ollama pull bge-m3`.
12. **DNS/файрвол:** A-записи 4 доменов → 45.91.237.204; файрвол провайдера — порты из §1.

## 4. Восстановление данных (restore)

**Где живут данные:** `/srv/nextcloud/pgdata` (БД Nextcloud) + `/srv/nextcloud/html/data`;
`/srv/openclaw/.openclaw` (openclaw.json, agents, extensions, credentials, browser, media);
`/srv/shared/*`; БД BAS-IP Monitor (postgres:16 volume `basip-monitor-postgres-1`);
`/srv/projects/bas-ip-monitor/secrets`. **Точки бэкапов:** `/srv/openclaw/backups/`
(`nextcloud-db`, `basip-git`, `memory-*`, `model-override-*`, `pairing-*`, `upgrade-*`, `skill-*.tgz`)
и `/srv/openclaw/captures`, `/srv/shared/captures`.

**Порядок restore:**
1. Бутстрап §3 (шаги 1–6) → конфиги из `infra/` + секреты из хранилища.
2. Данные: распаковать бэкапы `/srv/openclaw/backups/` на место; `pgdata` — либо каталогом, либо
   `pg_restore` из `nextcloud-db`.
3. Стеки поднять (§3 шаги 7–11), конфиги OpenClaw — `.openclaw` целиком.
4. Проверка: §5.

> ⚠️ **Автоматических регулярных бэкапов нет** (crontab пуст) — актуальность `/srv/openclaw/backups`
> не гарантируется. Автоматизация бэкапов и регулярный прогон restore — открытый пункт OPF-4.
