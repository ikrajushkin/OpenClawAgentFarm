|---|---|
| oc-node1 (ОС) | Ubuntu 26.04.1 LTS, ядро 7.0.0-30-generic |

| PostgreSQL | 17-alpine (nc-db, Nextcloud) · 16-alpine (basip-monitor-postgres-1) |
| Redis | 7-alpine (nc-redis) |
| Caddy | 2-alpine (edge `caddy` + `basip-monitor-caddy-1`) |
| Docker / Compose | Docker + containerd · Docker Compose v5.5.0 |
| Ollama | `ollama.service`, модель эмбеддингов `bge-m3` |
| LLM (основная цепочка) | DeepSeek `deepseek-v4.1-flash` через `polza-ds`, фолбэки `deepseek-v4-flash` ×2 — см. [ADR-004](ADR/ADR-004-model-chain-deepseek-polza.md) |
| STT | **Parakeet** `nemo-parakeet-tdt-0.6b-v3` (активный); whisper.cpp `ggml-medium-q5_0` — резерв |
| TTS | **Microsoft** `ru-RU-SvetlanaNeural` (активный); Piper `ru_RU-irina-medium` — резерв |
| Мониторинг | zabbix-agent :10050 |
