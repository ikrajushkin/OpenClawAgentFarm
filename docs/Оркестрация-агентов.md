## 1. Что такое OpenClaw (по фактическому наблюдению)

Да — это платформа **управления и оркестрации AI-агентами** («All your chats, one OpenClaw»): один
Gateway (ws 172.18.0.1:18789, Control UI) управляет множеством **изолированных агентов** — у каждого
свой workspace, auth-store, модельный роутинг и привязки каналов (Telegram, MAX, Signal, webhooks).
В комплекте: cron-автоматизации, скиллы, инструменты (браузер, голос, семантическая память), approvals,
Docker-sandbox, durable tasks/TaskFlow, A2A (агент→агент), worktrees, attach внешних CLI (Claude Code),
audit/telemetry/security-audit. Модель доверия — «personal assistant» (один доверенный оператор).

## 3. Проблемы (узкие места)

1. **Безопасность:** три находки security-audit закрыты 2026-10-14 (0 critical / 0 warn); осталось:
   tools.elevated включён, политика approvals не настраивалась.
2. **Отказоустойчивость:** закрыто 2026-10-14 — heartbeat `main` восстановлен, Signal удалён.
3. **Наблюдаемость:** учёт токенов/стоимости работает (6.72M токенов/день, `--json`), метрики идут в
   Zabbix (`custom.openclaw.usage.*`); остаток — элементы данных и алерты на стороне Zabbix-сервера.
4. **Консистентность:** workspace `ksu` вне `/srv/shared` (нарушает ADR-003, не попадает в общие
   бэкапы); идентичности из разных источников (config vs IDENTITY.md); у `ksu` отдельный ключ polza-ksu
   (целевое разделение? — не задокументировано).
5. **Неиспользуемый потенциал:** sandbox, active-memory/Dreaming, A2A-делегирование, webhooks, TaskFlow.

### Средний горизонт

5. **Включить active-memory + Dreaming** — консолидация памяти между разговорами, «Remember»;
   повысит качество контекста агентов (сейчас память ограничена индексом 69 файлов).
6. **Политика approvals:** allowlist для exec/tools.elevated, standing grants для автоматизаций
   (BAS-IP-такты), обязательный approve для опасных операций из чатов.
7. **Docker-sandbox** для скиллов с исполнением кода — изоляция от хоста (сейчас всё «на голом железе»).
8. **Автоматизации инфраструктуры:** cron-задачи агента `service` — health-check (docker ps, диск,
   сертификаты, fail2ban) с доставкой в Telegram; дайджест долгов из `docs/`; автоматизация бэкапов
   (закрывает остаток OPF-4).
9. **TaskFlow / durable tasks + worktrees** — длинные задачи (BAS-IP) как устойчивые фоновые jobs
   вместо ручных сессий; параллельные ветки работы в workspace.

### Стратегический горизонт

10. **Мультиагентная оркестрация:** делегирование `main` → `service`/`ksu` (A2A или `oc agent --to`),
    ролевая модель (ops / docs / home), subagent-разведка для инвентаризаций.
11. **Интеграции:** webhooks (Zabbix-алерты → агент-реагирует; GitHub), `oc message send` в скрипты
    сервера, users/email-aliases.
12. **Multi-tenant при росте:** если появятся другие пользователи/организации — отдельная Gateway-cell
    на тенанта (прямая рекомендация security-audit).
13. **Обновление OpenClaw** (`oc update`) — держать платформу в свежей версии (сейчас 2026.8.2).
