# Конвенция типизированных связей (граф знаний)

Связи между сущностями (ADR, инциденты `§N.N`, долги, спринты, требования `ТЗ§x.y`, концепты) делаем
**явными, типизированными и машиночитаемыми**. Из них генерируется [`Граф-знаний.md`](Граф-знаний.md) —
**актуальный по построению** (рисуется из рёбер, а не руками, поэтому не дрейфует).

## Как объявить связь

Одна строка в любом markdown-доке, рядом с фактом (под заголовком ADR/инцидента, у строки долга):

```
Связи[ИСТОЧНИК]: тип=цель,цель2 · тип2=цель3
```

- **ИСТОЧНИК и цели — ID:** `ADR-0xx` · `§N.N` (инцидент / раздел грабель) · ID долга (`OPF-1`) ·
  спринт (`С21.5`) · требование (`ТЗ§x.y`) · либо slug-концепт (`bas-ip-monitor`, `oc-node1`).
- Несколько типов в строке — через `·` или `;`. Несколько целей одного типа — через запятую.
- Ставить **в том же коммите**, что и сам факт (дисциплина «пишу насквозь»).

## Словарь типов (закрытый)

| Тип | Смысл | Инверсная форма (тоже допустима) |
|---|---|---|
| `supersedes` | заменяет | `superseded-by` |
| `implements` | реализует (ТЗ/ADR) | `implemented-by` |
| `closes` | закрывает (долг) | `closed-by` |
| `reopens` | переоткрывает | — |
| `blocks` | блокирует | `blocked-by` |
| `causes` | вызывает | `caused-by` |
| `recurs` | рецидив / повтор | — |
| `relates` | связано (симметрично) | — |
| `depends-on` | зависит от | `depended-on-by` |

Инверсные формы (`*-by`) генератор разворачивает в каноническое направление сам.

## Правило без фанатизма

Ребро — только там, где несёт **решение или навигацию**: родословная (`supersedes`), причинность
(`causes`/`recurs`), закрытие долга (`closes`), реализация требования (`implements`), ключевая зависимость.
**Не на каждое упоминание ID.**

## Генерация

```
python scripts/gen-knowledge-graph.py            # перезаписать Граф-знаний.md
python scripts/gen-knowledge-graph.py --check     # exit 1, если граф устарел
```

Источник рёбер — строки `Связи[…]` во всех `docs/**` (кроме самого графа и этого файла-конвенции).

**Авто-проверка (pre-commit):** в репо есть `.githooks/pre-commit`, гоняющий `--check`. Включить в клоне
однократно: `git config core.hooksPath .githooks`. Тогда устаревший граф блокирует коммит (обойти — `--no-verify`).

## Носитель

Каноничный носитель — **инлайн-строка `Связи[…]`** (единый парсер, без YAML). Связи «модуль → модуль»
(`depends-on`) в перспективе можно генерировать из кода (импорты / граф зависимостей), а не писать руками.
