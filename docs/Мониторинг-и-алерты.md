## Как это устроено

Два cron-скрипта (root, `/etc/cron.d/openclaw-metrics`, каждые 10 минут) собирают JSON в
`/var/lib/openclaw-metrics/`, zabbix-agent (v1, `:10050`) отдаёт их по UserParameter:

| Скрипт | Файл данных | Копия в `infra/` |
|---|---|---|
| `/usr/local/bin/openclaw-usage-refresh.sh` | `usage.json` (usage-cost `--json`, все агенты) | `openclaw/usage-refresh.sh` |
| `/usr/local/bin/openclaw-health-refresh.sh` | `health.json` (gateway, cron, heartbeats) | `openclaw/health-refresh.sh` |

## Ключи zabbix-agent (UserParameter)

| Ключ | Значение | Источник |
|---|---|---|
| `custom.openclaw.usage.cost` | расход за день, $ | usage.json |
| `custom.openclaw.usage.tokens` | всего токенов за день | usage.json |
| `custom.openclaw.usage.input` / `.output` / `.cache_read` | разбивка токенов | usage.json |
| `custom.openclaw.gateway.active` | 1/0 — жив ли Gateway (live-проверка) | systemctl |
| `custom.openclaw.cron.jobs` | число автоматизаций | health.json |
| `custom.openclaw.cron.errors` | число задач в `lastRunStatus=error` | health.json |
| `custom.openclaw.heartbeat.main` / `.ksu` / `.service` | статус последнего heartbeat | health.json |
| `custom.openclaw.backup.status` | `ok`/`error` — последний прогон бэкапа | backup.json (`oc-backup.sh`) |
| `custom.openclaw.backup.age_hours` | часов с последнего успешного бэкапа | backup.json |
| `custom.openclaw.backup.sizeMb` | размер последнего бэкапа, MB | backup.json |
| `custom.openclaw.restore.status` | `ok`/`error` — последняя restore-дрель | restore-test.json (`oc-restore-test.sh`) |
| `custom.openclaw.factory.drift` | `ok`/`drift`/`error` — сверка «конфиг ≠ анкеты» фабрики агентов | factory-drift.json (`oc-factory-drift.sh`, cron 4×/сутки) |

Проверка с хоста: `zabbix_agentd -t <ключ>`. Конфиги — `infra/zabbix/openclaw-usage.conf`,
`infra/zabbix/openclaw-health.conf`, `infra/zabbix/openclaw-backup.conf`,
`infra/zabbix/openclaw-factory.conf` (на сервере в `/etc/zabbix/zabbix_agentd.d/`).

## Элементы данных и триггеры для Zabbix-сервера

Полная спецификация (типы, интервалы, выражения триггеров) —
[`../infra/zabbix/openclaw-triggers.md`](../infra/zabbix/openclaw-triggers.md). Кратко:

- **OpenClaw Gateway down:** `custom.openclaw.gateway.active` = 0 → High;
- **Автоматизация в ошибке:** `custom.openclaw.cron.errors` > 0 → Warning;
- **Heartbeat агента упал:** `custom.openclaw.heartbeat.*` содержит `error` → Warning;
- **Дневной расход > 50 $:** `custom.openclaw.usage.cost` > 50 → Information;
- **Бэкап устарел/неудачен:** `custom.openclaw.backup.age_hours` > 30 ИЛИ
  `custom.openclaw.backup.status` ≠ `ok` → High;
- **Restore-дрель не прошла:** `custom.openclaw.restore.status` ≠ `ok` → Warning;
- **Дрейф конфига фабрики:** `custom.openclaw.factory.drift` ≠ `ok` (ручная правка
  `openclaw.json` мимо фабрики или неприменённая анкета) → Warning.
