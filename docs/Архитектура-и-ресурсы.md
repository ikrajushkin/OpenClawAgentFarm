## Топология сервисов

```
Internet ── :80/:443 ──> Caddy (edge, 172.18.0.10 в docker-сети, TLS/HSTS)
                            ├─ cloud.paylama.tech ──> nc-app:80 (+ /push/* → nc-push:7867)
                            ├─ oc.paylama.tech ─────> 172.18.0.1:18789 (OpenClaw Gateway, закрыт снаружи)
                            └─ paylama.online ──────> basip-monitor-app-1:8000 (/metrics → 404)
```

### 1. Caddy (edge / TLS-терминация)

- `/srv/caddy`: `Caddyfile`, `compose.yaml`; контейнер `caddy` (caddy:2-alpine), порты 80, 443/tcp+udp (HTTP/3).
- TLS-контакт `maintechlead@yandex.ru`, admin off; HSTS + security-headers на всех доменах.
- Решения о роли Caddy — [ADR-001](ADR/ADR-001-caddy-edge-proxy.md).

### 2. Nextcloud 34 — https://cloud.paylama.tech

- `/srv/nextcloud`: `compose.yaml`, `Dockerfile` (образ `nextcloud-shared:34`), `html/`, `pgdata/`, `.env`.
- Контейнеры: `nc-app`, `nc-push` (notify_push, :7867), `nc-cron`, `nc-redis` (redis:7-alpine), `nc-db` (postgres:17-alpine).
- notify_push за `handle_path /push/*` (срезает префикс, как тейлинг-слой в nginx).

### 3. OpenClaw Gateway — https://oc.paylama.tech

- systemd `openclaw-gateway.service` (User=`openclaw`, `/srv/openclaw`, `NODE_ENV=production`,
  `MemoryMax=6G`, `UMask=0002`, `ReadWritePaths=/srv/openclaw /srv/shared /tmp`).
- Слушает `172.18.0.1:18789` + `127.0.0.1:18789` (Control UI), `127.0.0.1:18799`; доступ только через Caddy.
- Встроенный браузер (chrome) на `127.0.0.1:18800`; Telegram-бот @MainTechOpenClaw_Bot (chat_id 10292232).
- **Модели (реальный статус 2026-10-14, `oc models status`):** цепочка LLM —
  **`polza-ds/deepseek/deepseek-v4.1-flash`** (основная) + фолбэки `polza-ds/deepseek/deepseek-v4-flash`
  и `…-0731`; у второго профиля — `polza-ksu-ds/deepseek/deepseek-v4.1-flash`. Utility/image-модели не
  настроены. Авторизация — **только провайдеры `polza*`** (API-ключи в профиле агента). Токен Anthropic
  **удалён 2026-10-14** (недействителен; см. [ADR-004](ADR/ADR-004-model-chain-deepseek-polza.md)).
  ⚠️ RUNBOOK сервера всё ещё описывает Sonnet 5/Haiku 4.5 как дефолт — устарело (материализация риска OPF-3).
- Управление — команда `oc` (обёртка над `openclaw` от сервисного пользователя; под root не вызывать — §1.2).
- **Плагины/эффективность (N4, 2026-10-23):** `tokenjuice` (`@openclaw/tokenjuice@2026.8.2`, npm-проект
  в `~/.openclaw/npm/projects/`, компакт exec-результатов) установлен и включён; rolling-детекторы
  зацикливания включены (`tools.loopDetection.enabled=true`; post-compaction guard — изначально);
  `toolSearch` — unset (авто-structured, не трогали). `plugins.allow` = 21 id (tokenjuice добавлен
  install'ом автоматически). Smoke-тест пройден; грабли установки — §1.8.
- Решение о размещении — [ADR-002](ADR/ADR-002-openclaw-gateway-systemd.md).

## Уточнения инвентаризации (сверка 2026-10-14, поздний проход)

Факты, обнаруженные при проверке «достаточности описания для полного восстановления»:

- **Сеть:** в `/etc/netplan` рядом с `50-cloud-init.yaml` лежит `60-gre-lab.yaml` — **GRE-туннель**
  (лабораторная топология), в доках ранее не отражён; есть бэкапы `/root/netplan-backup-20260924-*`.
- **Образы Docker (точные на 2026-10-14):** `nextcloud-shared:34` (2.19 GB, слой `nextcloud:apache`),
  `basip-monitor-app:latest`, `basip-test:local`, `basip-migration-test-app:latest`, `basip-smoke-app:latest`
  (последние два — тестовые, в контейнерах не запущены), `postgres:17-alpine`, `postgres:16-alpine`,
  `redis:7-alpine`, `caddy:2-alpine`, `alpine:latest`. Теги плавающие (без digest-пинов).
- **Nextcloud:** кастомный `Dockerfile` (на базе `nextcloud:apache`), `compose.yaml` с тюнингом Postgres
  (`shared_buffers=1GB`, `work_mem=16MB`, `mem_limit`), включённые приложения — notify_push 1.4.0, office 1.0.0
  и стандартный набор 34-й версии.
- **BAS-IP Monitor:** в проекте есть `docker/Dockerfile`, `docker/docker-compose.yml`, `docker/Caddyfile`;
  в `secrets/` — `master.key`, `syslog.key` (секреты, в доки не копируются).
- **OpenClaw:** состояние в `/srv/openclaw/.openclaw/` — `openclaw.json` (+десятки `.bak-*` бэкапов конфига),
  `agents/`, `extensions/`, `credentials/`, `browser/`, `media/`, `migration/` — прикладная конфигурация
  целиком в этих файлах, в репо не выгружена.
- **Хост:** fail2ban (`jail.local`, `jail.d/defaults-debian.conf`), crontab root пуст, `/etc/cron.d` —
  только штатный `e2scrub_all`.
- **RUNBOOK на сервере:** `/srv/openclaw/RUNBOOK.md` — 1758 строк (в `/root` — 162 строки, компактная версия).
