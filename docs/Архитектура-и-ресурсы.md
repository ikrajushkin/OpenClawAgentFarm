## Топология сервисов

```
Internet ── :80/:443 ──> Caddy (edge, 172.18.0.10 в docker-сети, TLS/HSTS)
                            ├─ cloud.paylama.tech ──> nc-app:80 (+ /push/* → nc-push:7867)
                            ├─ oc.paylama.tech ─────> 172.18.0.1:18789 (OpenClaw Gateway, закрыт снаружи)
                            └─ paylama.online ──────> basip-monitor-app-1:8000 (/metrics → 404)
```

### 1. Caddy (edge / TLS-терминация)

- `/srv/caddy`: `Caddyfile`, `compose.yaml`; контейнер `caddy` (caddy:2-alpine), порты 80, 443/tcp+udp (HTTP/3).
- TLS-контакт `maintechlead@yandex.ru`, admin off; HSTS + security-headers на всех доменах.
- Решения о роли Caddy — [ADR-001](ADR/ADR-001-caddy-edge-proxy.md).

### 2. Nextcloud 34 — https://cloud.paylama.tech

- `/srv/nextcloud`: `compose.yaml`, `Dockerfile` (образ `nextcloud-shared:34`), `html/`, `pgdata/`, `.env`.
- Контейнеры: `nc-app`, `nc-push` (notify_push, :7867), `nc-cron`, `nc-redis` (redis:7-alpine), `nc-db` (postgres:17-alpine).
- notify_push за `handle_path /push/*` (срезает префикс, как тейлинг-слой в nginx).

### 3. OpenClaw Gateway — https://oc.paylama.tech

- systemd `openclaw-gateway.service` (User=`openclaw`, `/srv/openclaw`, `NODE_ENV=production`,
  `MemoryMax=6G`, `UMask=0002`, `ReadWritePaths=/srv/openclaw /srv/shared /tmp`).
- Слушает `172.18.0.1:18789` + `127.0.0.1:18789` (Control UI), `127.0.0.1:18799`; доступ только через Caddy.
- Встроенный браузер (chrome) на `127.0.0.1:18800`; Telegram-бот @MainTechOpenClaw_Bot (chat_id 10292232).
- Модели: Sonnet 5 (основная) / Haiku 4.5 (резерв); авторизация — setup-token подписки (до 2027-08-31)
  в `/etc/openclaw/env` (640 `root:openclaw`; значения в доки не копируем).
- Управление — команда `oc` (обёртка над `openclaw` от сервисного пользователя; под root не вызывать — §1.2).
- Решение о размещении — [ADR-002](ADR/ADR-002-openclaw-gateway-systemd.md).

### 4. BAS-IP Monitor — https://paylama.online

- Код: `/srv/projects/bas-ip-monitor` (`Makefile`, `api/`, `backend/`, `frontend/`, `docker/`, `docs/`,
  `scripts/`, `tools/`, `secrets/`, `data/`).
- Контейнеры: `basip-monitor-app-1` (basip-monitor-app, :8000, healthy), `basip-monitor-postgres-1`
  (postgres:16-alpine), `basip-monitor-caddy-1` (caddy:2-alpine, публикует :8080).

### 5. AI/ML-стек (хост)

- `ollama.service` — localhost:11434, модель `bge-m3` (эмбеддинги, 1.2 GB).
- `/opt`: `whisper.cpp` + `whisper-models` (STT), `piper` + `piper-voices` (TTS), `parakeet`,
  `miniforge`, `hf-cache`, `ttsbench`, `google`, `containerd`.
- Конфигурация STT/TTS — env-переменные `/etc/openclaw/env` (`WHISPER_CPP_MODEL*`).

### 6. Инфраструктура хоста

- Docker + containerd (compose-проекты в `/srv/nextcloud`, `/srv/caddy`), Docker Compose v5.5.0.
- zabbix-agent (:10050), fail2ban, chrony, rsyslog, unattended-upgrades, qemu-guest-agent, systemd-networkd/resolved.

## Файловая топология `/srv`

| Путь | Назначение |
|---|---|
| `/srv/openclaw` | домашняя директория OpenClaw: `RUNBOOK.md`, `.openclaw/`, `workspaces/`, `captures/`, `backups/`, `secrets/` |
| `/srv/nextcloud` | compose-проект Nextcloud + данные (`html/`, `pgdata/`) |
| `/srv/caddy` | compose-проект edge Caddy + `Caddyfile` |
| `/srv/projects/bas-ip-monitor` | код проекта BAS-IP Monitor |
| `/srv/shared` | общая зона обмена: `Workspace/`, `Inbox/`, `Outbox/`, `Docs/`, `Projects/`, `Media/`, `captures/` (group `shared`, setgid, UMask 0002) — [ADR-003](ADR/ADR-003-shared-file-zone.md) |

`/root` сервера содержит сотни эксплуатационных скриптов (`tts-*`, `voice-*`, `fix-*`, `diag-*`, `f*-*.sh`)
и бэкапы (`netplan-backup-*`, `*.tgz`) — археология отладки 2026-09; при разборе — опираться на
серверный RUNBOOK (OPF-3).
